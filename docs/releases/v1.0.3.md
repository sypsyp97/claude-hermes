## Upgrade requirements

Upgrade to **Claude Code 2.1.257+** before updating Hermes; compatibility was checked
against 2.1.269. Newly scoped bridge conversations start fresh rather than guessing
ambiguous legacy history into another user's session.

## Highlights

- More robust Discord heartbeat/resume and Telegram polling, bounded requests and
  cancellation, rate-limit handling, and no automatic replay of uncertain agent tasks.
- Consistent session/channel policies, auto-thread routing, ordered controls and
  thread deletion, including fixes for shared-session races and deletion deadlocks.
- Proactive scoped recall with FTS5, Chinese retrieval support, explicit remembered
  facts, provenance/expiry filters, and clear reset versus forget behavior.
- Native Claude resume/fallback, scoped auto memory, streaming/error handling and
  shared execution limits for Claude and speech recognition.
- Updated English/Chinese READMEs and detailed session/compatibility documentation.

The runtime fixes passed ten fresh-context review rounds; the final review found
no actionable issues. Release publication additionally requires the complete
Ubuntu/macOS × Bun 1.3.4/latest verification matrix.

Real bot connections and model-generated memory quality still require deployment
acceptance. No runtime dependency or schema migration was added.
